核心功能

不只是历史记录

Clip 把剪贴板变成一个真正有用的工作台。

📋

自动历史记录

实时捕获文本与图片，最多保存 300 条，退出时可持久化到本地。

📁

分组管理

创建命名分组，激活后所有新内容自动归入该分组，随时切换。

🔍

快速搜索

复制关键词后一键搜索，在海量历史中秒定位目标内容。

🌈

颜色识别转换

自动识别 Hex 色值，一键转换为 RGB，设计师必备。

🌍

实时翻译

接入百度翻译 / 有道翻译，复制即翻译，结果显示在托盘标题。密钥安全存储在系统凭据库。

🌐

局域网共享

一台开启服务端，另一台连接，两台电脑剪贴板实时同步，甚至可以"聊天"。

快速上手

三步开始使用

安装后常驻系统托盘，左键查看历史，右键访问全部功能。

1

下载并运行

从 Releases 页面下载对应平台的可执行文件，双击运行，图标出现在系统托盘。

2

左键查看历史

点击任意条目即可复制到剪贴板，支持文本与图片。

3

右键配置功能

开启翻译、颜色识别、局域网共享，或创建分组管理不同类别的内容。

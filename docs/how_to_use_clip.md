# 开源剪切板历史工具 《clip》怎么使用，详细图解

Clip 是一个驻留在系统托盘的剪贴板历史管理工具，自动记录你复制过的文本和图片，支持分组管理、快速搜索、颜色格式转换、百度/有道翻译和局域网实时共享，完全免费开源（GPL-3.0）。

支持 macOS、Windows、Linux 三大平台。

> 文中截图待补充，占位路径为本文档同级的 `images/` 目录。

## 设计理念

剪贴板历史工具不需要太多花哨的功能。平时默默在后台记录，需要时能快速复制回来，就够用了。

"快速呼出"怎么解决？常见方案是设快捷键。但我电脑上的快捷键实在太多，不想再记一个新的。

又不想牺牲速度。权衡之后，我选了**托盘直接呼出**：不用记任何快捷键，鼠标一点，历史就在眼前。

## 下载、安装

### 下载

打开 [GitHub Releases](https://github.com/DoYoungDo/clip/releases/latest)，根据你的系统选择对应压缩包：

| 系统 | 说明 |
|:--|:--|
| macOS Apple Silicon | `*-darwin-arm64.zip` |
| macOS Intel | `*-darwin-amd64.zip` |
| Linux | `*-linux-amd64.tar.gz` |
| Windows | `*-windows-amd64.zip` |

### 安装

解压后即可得到可执行文件，无需安装过程：

- **macOS**：将 `clip` 拖入「应用程序」或任意目录后双击运行。
  由于应用未签名，首次打开可能被拦截，请参考 [mac 安装未知应用常见问题](https://doyoungdo.github.io/essay/#/Other/mac_install_unknown_app) 解除限制。
- **Windows**：解压后双击 `clip.exe` 运行。
- **Linux**：解压后赋予执行权限后运行：`chmod +x clip && ./clip`

程序启动后**没有任何窗口**，请留意屏幕角落的系统托盘区出现 Clip 图标，即为启动成功：

![图1：系统托盘图标](images/01-tray-icon.png)

之后的所有操作都围绕托盘图标展开。

## 使用

### 两个入口：左键与右键

- **左键**点击托盘图标：显示剪贴板历史记录，点击任意一条即复制到剪贴板，这是最常用的操作。
- **右键**点击托盘图标：打开完整功能菜单（历史、分组、搜索、配置等）。

![图2：左键历史菜单](images/02-left-click-menu.png)

![图3：右键完整菜单](images/03-right-click-menu.png)

### 看懂历史记录条目

历史记录按时间倒序排列（最新在最上方），每条记录的格式为：

```text
📝 [15:04] 复制的文本内容
🖼️ [15:04] 图片 [a1b2c3d4]
📝 [15:04] [R] 来自局域网共享的内容
```

- `📝` / `🖼️`：区分文本和图片
- `[15:04]`：记录时间
- `[R]`：该内容来自局域网共享，而非本机复制
- 文本超过 40 字符会截断显示为 `...`，鼠标悬停可查看完整内容
- 图片默认显示为 `图片 [哈希前8位]`，重命名后显示名称

![图4：历史记录条目格式](images/04-history-item.png)

### 关键机制：最新一条是所有"输入"的来源

历史记录最上面那条（最新复制的）是一条特殊记录：**所有需要内容作为输入的功能，读取的都是它**。因此 Clip 的操作习惯永远是"先复制，再点菜单"：

- ➕ 创建分组：以最新一条作为分组名
- 分组「重命名」、图片「重命名」：以最新一条作为新名称
- 翻译器启用：以最新一条作为密钥（如 "appkey 密钥"）
- 局域网共享「连接到」：以最新一条作为服务地址
- 「设置最大历史记录条数」：以最新一条作为数字
- 🔎 搜索：以最新一条作为关键词

注意：这些功能要求最新一条必须是**文本**。如果最新记录是图片，操作会无效，先复制一段文本再操作即可。

### 条目右键：更多操作

默认情况下，右键菜单中点击历史条目会**直接复制**，没有二级菜单。只有开启了对应的扩展功能配置后，条目下才会出现二级操作菜单：

- **复制**：点击即复制该条目
- **复制Hex / 复制RGB**：颜色格式转换（开启「自动识别颜色」后，颜色值文本条目显示）
- **重命名**：为图片命名，名称取自最新的剪贴板文本（开启「图片重命名」后，图片条目显示）
- **删除**：删除单条记录（开启「单独删除项」后显示，防止误触）

![图5：条目二级菜单](images/05-item-context-menu.png)

### 清空历史记录

右键菜单中点击「清空历史记录」后不会立即清除，菜单会变为「确认/取消清空历史记录？」，再点一次「确认清空？」才会真正清空，点「取消清空?」放弃操作。

> 清空历史记录不会清空剪贴板中的当前内容。

![图6：清空历史记录二次确认](images/06-clear-history.png)

### 分组管理

分组可以把某一类剪贴板内容单独收纳，例如把工作相关的资料集中到一个分组里。

**创建分组**（分组名取自剪贴板）：

```text
1. 复制文本 "工作笔记"（作为分组名）
2. 右键 → ➕ 创建分组
```

**激活分组**：右键点击分组名 → 「激活/取消激活分组」。分组激活后（菜单中带 ✓），此后新复制的所有内容都会**同时**自动保存到该分组，相当于给剪贴板内容自动分类归档。激活多个分组时，内容会同时进入所有激活的分组。

**其他操作**（右键点击分组名展开）：

- **重命名**：把新名字复制到剪贴板，再点击「重命名」
- **删除分组**：删除分组及其收纳的全部历史
- 分组条目本身也可以点击复制、右键删除

![图7：创建分组](images/07-create-group.png)

![图8：分组子菜单](images/08-group-submenu.png)

### 搜索历史

用剪贴板内容作为关键词过滤历史记录：

```text
1. 复制关键词，例如 "密码"
2. 右键 → 🔎 搜索
3. 菜单中只显示包含 "密码" 的历史记录
4. 再次点击 🔎 搜索 取消
```

搜索规则：文本按「包含关键词」匹配；图片按「相同图片」匹配——复制一张图片后搜索，历史中同一张图片的所有记录都会筛出来。

![图9：搜索效果](images/09-search.png)

### 颜色识别与转换

写前端时经常在 Hex 和 RGB 之间来回换算，Clip 可以直接在剪贴板里完成：

```text
1. 右键 → 配置 → 勾选「自动识别颜色」
2. 复制 #FF5733
3. 右键点击该条目 → 出现「复制Hex / 复制RGB」
4. 点击「复制RGB」，得到 255,87,51
```

![图10：颜色识别与转换](images/10-color-convert.png)

### 翻译（百度 / 有道）

复制文本后自动翻译，结果显示在托盘标题上。

**配置密钥**（首次使用）：

```text
1. 复制翻译器密钥到剪贴板（注意 appid 和密钥之间用空格分隔）
   - 百度翻译: "appid 密钥"
   - 有道翻译: "appkey 密钥"
2. 右键 → 配置 → 翻译 → 点击对应翻译器
   （此时会联网验证一次密钥，验证失败则无法启用）
3. 选择「翻译为：zh / en」设定目标语言
```

未配置密钥的翻译器，菜单名会直接提示格式（如「有道翻译，请确保当前剪切板的内容为：appkey 密钥」）；配置成功后显示为「有道翻译（已配置密钥）」，一眼可知该平台已配置、点击即可启用。

**使用**：之后每次复制文本，托盘标题会实时显示译文，译文同时写入剪贴板历史，方便回看。

![图11：翻译菜单与密钥配置](images/11-translate-config.png)

![图12：托盘标题显示翻译结果](images/12-translate-result.png)

**删除密钥**：右键 → 配置 → 翻译 → 删除密钥 → 点击对应平台。会同时清除系统凭据存储中的密钥和本地的启用状态，删除后可按上面的步骤重新配置。

![图13：删除密钥](images/13-delete-secret.png)

> **密钥安全**：密钥不会写入 `config.json`，而是保存在系统凭据存储中（macOS Keychain / Windows 凭据管理器 / Linux Secret Service）。如果系统凭据存储不可用，翻译器将无法在重启后自动恢复启用状态。

### 局域网共享

**场景**：两台电脑（同一局域网）互相共享剪贴板，甚至可以通过复制文本在菜单中"聊天"。

**电脑 A（服务端）**：

```text
1. 右键 → 配置 → 局域网共享 → 点击「局域网共享」
2. 服务地址（如 192.168.1.100:54321）自动复制到剪贴板
```

**电脑 B（客户端）**：

```text
1. 粘贴并复制地址 192.168.1.100:54321
2. 右键 → 配置 → 局域网共享 → 「连接到」
3. 连接成功，A 复制的内容会实时出现在 B 的历史记录中（带 [R] 标记）
```

连接列表会显示在「局域网共享」子菜单中，点击某条地址即可断开对应连接。

**"聊天"示例**：

```text
电脑 A: 复制 "晚上一起吃饭吗？"
电脑 B: 在历史记录中看到 [R] "晚上一起吃饭吗？"
电脑 B: 复制 "好啊，几点？"
电脑 A: 看到回复 [R] "好啊，几点？"
```

### 配置项详解

右键 → 配置：

| 配置项 | 说明 |
|:--|:--|
| 单独删除项 | 开启后，历史条目右键会出现「删除」按钮 |
| 自动识别颜色 | 开启后，复制颜色值可转换为 Hex / RGB |
| 设置最大历史记录条数 | 用**剪贴板数字**设置：复制一个 1-300 的数字后点击菜单项，默认 300，超过自动丢弃最早记录 |
| 相同内容只保留最新 | 开启后相同内容只保留最近一条，开启瞬间会清理历史中的重复项 |
| 图片重命名 | 开启后可右键图片「重命名」，名称取自最新剪贴板文本 |
| 局域网共享 | 见上文「局域网共享」 |
| 翻译 | 见上文「翻译」 |
| 打开配置文件目录 | 直接打开 `config.json` 所在目录 |
| 退出时保存日志 | 退出程序时把运行日志写入 `clip.log` |

![图16：配置菜单](images/16-config-menu.png)

### 数据与日志位置

配置文件、历史记录和日志都保存在系统配置目录的 `Clip` 文件夹下：

- **macOS**：`~/Library/Application Support/Clip/`
- **Linux**：`~/.config/Clip/`
- **Windows**：`%AppData%/Clip/`

- `config.json`：配置与历史记录（含分组）
- `clip.log`：运行日志（开启「退出时保存日志」后，退出时生成）

## 总结

Clip 把剪贴板从"只能存一条"升级成一个带历史、分组、搜索的多条目管理器：

- 📋 文本/图片历史自动记录，左键一键回贴
- 📂 分组归档，激活后自动分类
- 🔍 剪贴板即搜索框，图片按图搜图
- 🌍 复制即翻译，密钥存系统钥匙串更安全
- 🌐 局域网共享，多台电脑剪贴板互通
